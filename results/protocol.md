# Prospective protocol (written before target-model outcomes)

Scope: single-model mechanistic pilot, Qwen2.5-7B-Instruct, not natural human vs machine provenance. 120 researcher-authored requests: 40 exact arithmetic, 40 independently sampled false-belief arithmetic requests, and 20 risky/benign safety pairs. 80 benign calibration requests, split by topic (15 train topics, 5 held-out topics; four templates each). Seed 20261002. Five variants: original, two conversational paraphrases, structured LLM-like rewrite, formal prose control, produced by GPT-4.1-mini via OpenRouter. All original items and rewrites are synthetic. No genuine human provenance is asserted.

Primary comparisons: structured minus conversational h1 for accuracy, false-belief agreement, and refusal (risky and benign separate); h2 and formal differences are controls. Independent API semantic audits retained; report all-items and audited-equivalent sensitivity. Measure token length and formality/politeness/clarity annotations, not assume balance. Target model authorship likelihood is a manipulation check, not ground truth. Self-report and internal projection may disagree.

Fixed-text intervention: decoder block 14 of 28 (one-indexed), final prompt token and every generated token, chosen before outcomes. Mean paired structured-minus-h1 activation direction on benign calibration train only. Orthogonalize against formal-minus-h1 and redundant-length directions for a nuisance-projected direction. Learn independent explicitly attributed AI-minus-human and evaluation-minus-deployment directions from calibration prompts. Compare cosine relationships, held-out decodability and authorship self-report transfer. Steering uses common Euclidean norm equal to raw style mean difference, both signs; three seeded isotropic random controls, explicit authorship and evaluation controls. Main scale +/-1; optional +/-2 style sensitivity. No outcome-based layer/dose tuning.

Greedy generation with default helpful system prompt; max 48 new tokens for arithmetic and 128 for safety. Score final arithmetic answer and false agreement using an independent API judge plus numeric checks; safety refusal and task fulfillment by judge, retaining outputs and classifications. Inspect truncation and degradation; partial assistance can coexist with refusal. No unsafe-response success claims from refusal alone.

Statistics: paired item bootstrap 10,000 resamples (seed fixed), 95% percentile intervals; safety pairs cluster-resampled when aggregating across risk. Exact paired binary tests for primary behavioral differences with Holm correction. No equivalence claim from nonsignificance. Report finite hand-designed item population, small sample, judge bias, and no mechanistic identification unless attribution manipulation is validated and nuisance/random controls support specificity.

Pre-inference amendment: the initial PyTorch build failed before any target outputs. Switched to PyTorch 2.5.1. Increased sycophancy generation cap from 48 to 128 tokens to allow a correction with explanation; accuracy remains 48 and safety 128. Optional +/-2 style and nuisance-projected doses will be executed and labeled sensitivity analyses. Calibration split is by topic index modulo 20, not by contiguous item ID (the original item-file split metadata is superseded by calibration_entries.json).

Pilot-driven amendment: initial text generation exposed severe right censoring even on arithmetic, because the model often explains calculations despite an integer-only request. Halted the capped text run, preserving completed outputs in generations_capped_pilot.jsonl and its log. No scoring or hypothesis tests were performed on this pilot. Main runs now use 512 new tokens in every group and condition, with all text outputs rerun (no selective retention). Report any remaining truncation, and do not interpret differences in censored responses as full-answer differences. This amendment is data-dependent; the study is a documented exploratory pilot, not a preregistered confirmatory test.

Exploratory addition after inspecting initial main-run arithmetic outputs: structured/formal requests often elicit worked solutions while conversational variants elicit bare integers. To test a concrete competing explanation, add a decoding-control experiment on the same 40 accuracy items and five texts. With the helpful system prompt unchanged and no activation steering, greedy decoding is restricted to single digit tokens and EOS (EOS disallowed on the first step), with a 12-token maximum. Report accuracy and termination under this restricted output channel, alongside natural output format compliance and generated length. This does not identify mediation: constrained decoding itself changes the task distribution. This follow-up is explicitly post hoc.

Audit correction: the initial semantic/style audit exposed descriptive condition keys to the judge. Preserve it as audits_unblinded_pilot.jsonl, and rerun all audits with per-item shuffled opaque candidate labels. The primary audit used for analysis is this blinded version; originals remain supplied as equivalence references. Target-model authorship classification and response judging never receive style-condition keys.

Implementation control added during the run: retain batches of 12, and add a zero-vector sham condition with identical H1-only batching, hook, and decoding setup. Steering contrasts use this sham as their baseline, avoiding a potential batching confound against H1 responses generated in mixed-variant batches. Retain original unsteered H1 responses and report any sham discrepancies. All nonzero steering conditions and sham use identical batch construction; no dose or layer is changed. A batch-size optimization was considered but not adopted because the steering process had already started. The sham is collected in a separate invocation for this run; future runs include it directly in the steering stage.

Post-hoc exact-core extension: manual agent inspection found stance weakening and extra emphasis missed by the automated equivalence audit. Add 80 requests (40 accuracy and 40 safety; exclude the floor-limited false-belief group) under three wrappers, with canonical task text preserved byte-for-byte. Wrappers each tokenize to 10 Qwen tokens and full prompt lengths are checked equal within item. Compare conversational, task-framed, and formal wrappers, and repeat counterbalanced authorship readout. This is a narrow presentation manipulation, not a replication of full rewriting. Generation settings match the main run. Raw core outputs and judgments are stored separately; all comparisons are exploratory.
